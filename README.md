# Performance Evaluation Metrics (Task 6)

This repository holds the automated reporting model built for my Data Analyst Internship at Internee.pk.

### Project Objective:
The core target of this module is to evaluate internal performance arrays by compiling key KPIs (Task Completion Time, Project Quality scores, and Mentor Feedback numbers) into a unified report.

### Technical Stack Used:
* **Python** (Backend Logic Framework)
* **Pandas & NumPy** (Array math operations and vectorized tracking columns)

### Performance Index Formula Applied:
* Performance_Index = (Project_Quality * Mentor_Feedback) / Completion_Time
* Implemented automatic descending sort (`.sort_values`) to map clear intern rankings for supervisor monthly reports.
